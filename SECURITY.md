# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch and the latest 0.1.x MVP release line.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, exposed credential, cross-tenant access problem, or unsafe document/AI handling behavior. Use GitHub private vulnerability reporting if it is enabled for this repository; otherwise contact the repository owner privately with:

- a concise description and impact;
- safe reproduction steps using synthetic data only;
- affected commit or endpoint; and
- suggested mitigation, if available.

Do not include API keys, session cookies, real customer documents, personal data, or production database details in the report.

The project will acknowledge reports, assess severity, and coordinate a fix before public disclosure.
