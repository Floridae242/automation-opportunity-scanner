# UX Specification

## Screens
- Login / organization selection
- Dashboard / portfolio
- Project detail
- New process intake
- Process extraction review
- Process map editor
- Analysis overview
- Opportunity detail
- Impact vs Effort matrix
- Executive report
- Audit/history
- Settings

## Critical UI behavior
- Clearly label AI draft vs human-reviewed state.
- Show confidence separately from opportunity score.
- Unknown values appear as “Not provided”, never 0.
- Score detail shows weight/contribution and evidence.
- ROI panel lists assumptions and missing inputs.
- Every AI failure has a retry/manual continuation path.
- Long-running analysis shows queued/running/completed/failed.

## Workshop mode
Optimize intake/review for a projector: readable density, quick editing, clear progress, and one-click move from extraction review to analysis.
