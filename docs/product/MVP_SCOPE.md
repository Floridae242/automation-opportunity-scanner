# MVP Scope

## Must have
- Authentication and one organization per demo user (multi-tenant data model).
- Project/process CRUD.
- Free-text process intake and guided operational metrics form.
- AI extraction of steps, actors, systems, inputs/outputs, decisions, pain points, and unknowns.
- Human review/edit before final scoring.
- Visual process map.
- Candidate automation opportunities and evidence.
- Deterministic opportunity score + confidence.
- Impact-vs-effort matrix.
- Technology recommendation with “why / why not / prerequisites”.
- ROI/time-saving calculation when sufficient inputs exist.
- Executive summary/report screen.
- Audit trail of analysis runs.

## Should have
- Text extraction from PDF/DOCX via safe parser service.
- Comparison between process versions.
- Portfolio filters by department/category/score/confidence.
- Export as JSON/CSV/PDF through a server-side report service.

## Won't have in 18-day MVP
- Direct enterprise-system write automation.
- Full BPMN authoring.
- Autonomous web/computer control.
- Complex custom workflow designer.
- Enterprise SSO/SCIM.
