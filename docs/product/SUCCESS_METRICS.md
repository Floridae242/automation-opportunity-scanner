# Success Metrics

## Product quality
- % of AI process drafts accepted with <= minor edits.
- Step/actor/system extraction accuracy on golden dataset.
- Unsupported recommendation rate.
- % of recommendations with valid evidence references.
- Human-rated usefulness and explainability.

## Workflow efficiency
- Median time from intake to reviewed first-pass assessment.
- Analyst minutes per assessed process.
- Number of processes compared in a portfolio session.

## Reliability
- Schema-valid AI responses.
- Analysis job success rate.
- P95 API latency excluding model inference.
- Model inference P50/P95 and cost per completed analysis.

## Safety/security
- Cross-tenant access test failures: target zero.
- Sensitive-data leakage test failures: target zero.
- Prompt-injection eval escape rate: measured and tracked.
