# Product Vision

## Vision statement
For organizations that need to identify where automation can create value, Automation Opportunity Scanner is a decision-support platform that converts messy workflow knowledge into a structured, evidence-backed opportunity portfolio. Unlike a generic chatbot, it combines process modeling, explicit business rules, deterministic scoring, human validation, and audit history.

## Jobs to be done
- “Help me turn this process description into a process model I can review.”
- “Show which steps are repetitive, manual, error-prone, delayed, or integration-heavy.”
- “Compare opportunities using the same scoring logic.”
- “Explain why a technology is recommended.”
- “Give management a concise prioritization report.”

## North-star outcome
High-quality **reviewed assessments per analyst-hour**, not raw model calls or number of generated recommendations.

## Product principles
Evidence-first; human-reviewable; explainable; technology-neutral; secure; progressively detailed; fast enough for workshops.
