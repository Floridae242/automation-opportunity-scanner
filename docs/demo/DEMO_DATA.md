# Demo Data Scenarios

## Scenario A — Invoice intake
Invoices arrive by email; finance downloads attachments, reads supplier/invoice fields, enters ERP, checks duplicates, asks manager approval, posts status. Use to demonstrate Document AI + workflow + integration opportunity.

## Scenario B — Employee onboarding
HR collects form/email information, creates accounts through multiple admin portals, sends checklist, follows up manually. Use to demonstrate workflow/integration and security/HITL considerations.

## Scenario C — Monthly management report
Analyst exports spreadsheets from multiple systems, cleans columns, reconciles totals, creates slides, emails managers. Use to demonstrate ETL/integration and assisted narrative generation while keeping numbers deterministic.

Each scenario should include a few known metrics and at least one unknown so the demo proves the product does not fabricate data.
