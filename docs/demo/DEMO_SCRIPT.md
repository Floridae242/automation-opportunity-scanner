# 7-Minute Demo Script

## 0:00–0:45 Problem
“Organizations can describe processes, but turning descriptions into a consistent automation portfolio takes analyst time and judgment.”

## 0:45–1:30 Intake
Create a process and paste a realistic workflow. Show operational questions; intentionally leave one metric unknown.

## 1:30–2:30 AI draft + review
Run extraction. Emphasize AI draft label, evidence, unknown field, and editable process map.

## 2:30–4:00 Opportunities
Confirm review. Show pain points and 3 candidate opportunities. Open score breakdown and explain deterministic calculation + separate confidence.

## 4:00–5:15 Recommendation
Show why API/workflow/document AI/RPA/LLM was or was not selected. Show prerequisites and human-control requirement.

## 5:15–6:15 Portfolio/ROI
Impact-vs-Effort matrix. Demonstrate that ROI is withheld when required cost data is absent, then add a scenario input and recalculate.

## 6:15–7:00 Architecture/close
Show audit/version metadata and summarize: “AI accelerates discovery; humans validate facts; deterministic logic makes prioritization reproducible.”
