# Definition of Done

A feature is done only when applicable boxes are true:
- [ ] Requirement/acceptance criteria linked.
- [ ] Type-safe implementation.
- [ ] Server authorization enforced.
- [ ] Tenant scope enforced.
- [ ] Input and output validation.
- [ ] Error/loading/empty UI states.
- [ ] Unit tests.
- [ ] Integration tests.
- [ ] Critical E2E updated.
- [ ] AI schema/eval updated when AI behavior changes.
- [ ] Audit/log/telemetry added for important operations.
- [ ] Migration added for schema change.
- [ ] Documentation updated.
- [ ] Lint/typecheck/tests pass.
- [ ] No secrets or fabricated demo logic in production path.
