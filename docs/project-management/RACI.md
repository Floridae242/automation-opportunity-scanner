# RACI — 4-Person Hackathon Team

| Workstream | A Product/UX | B Backend/Domain | C AI/Evals | D QA/DevOps |
|---|---|---|---|---|
| Requirements & demo story | A/R | C | C | C |
| UX & frontend shell | A/R | C | C | C |
| Database/domain model | C | A/R | C | C |
| API implementation | C | A/R | C | C |
| AI provider/prompts/schemas | C | C | A/R | C |
| Scoring/ROI rules | C | A/R | R | C |
| AI evaluation | C | C | A/R | R |
| E2E/security tests | C | C | C | A/R |
| CI/deployment/observability | C | C | C | A/R |
| Demo release decision | A | R | R | R |

A = Accountable, R = Responsible, C = Consulted. Each critical PR has at least one reviewer outside the primary owner.
