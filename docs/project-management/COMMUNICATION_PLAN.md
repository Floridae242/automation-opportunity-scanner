# Communication Plan

## Daily 15-minute stand-up
Yesterday / today / blocker / demo risk. End with one explicit decision or no-decision-needed.

## Daily integration demo
Before stopping work, run the latest vertical slice against shared demo data. Broken main/staging is a team issue, not one person's issue.

## Decision capture
Architecture/product decisions that can affect other work go in `DECISIONS.md` or a PR note; do not leave key decisions only in chat.

## Escalation
Blocker > 2 hours: ask teammate. Blocker > 4 hours or threatens P0: simplify/cut scope. External dependency unavailable: activate documented fallback.

## Day 15–18 change control
Only changes tied to failing acceptance criteria, security, demo reliability, or severe UX confusion. New ideas move to roadmap.
