# Prompt: Pain-Point Analysis — aos-painpoints v1.0.0

Analyze only the reviewed process facts provided. Identify delays, repetitive manual work, handoffs, copy/re-keying, errors/rework, system switching, document handling, manual tracking, and exception burden.

For each pain point return: category, affected step IDs, evidence, impact hypothesis, confidence, and missing information. Do not convert a hypothesis into a numeric fact.
