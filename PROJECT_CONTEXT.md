# Project Context

## Problem
Organizations often know that repetitive work exists but lack a fast, consistent way to convert informal workflow descriptions into a structured automation opportunity portfolio. Discovery is frequently manual, consultant-heavy, inconsistent across teams, and difficult to compare quantitatively.

## Product
The Automation Opportunity Scanner accepts a workflow description, guided questionnaire, or supported document text; extracts a draft process; asks a human to review it; identifies pain points and automation candidates; calculates an explainable opportunity score; recommends suitable automation approaches; and produces a prioritized report.

## Primary users
- Business Analyst: structures and validates processes.
- Automation/Integration Engineer: evaluates technical feasibility.
- Process Owner: supplies operational facts and approves assumptions.
- Consultant: runs discovery workshops and compares opportunities.
- Executive/Manager: consumes portfolio prioritization and reports.

## Core journey
Create project -> describe process -> AI draft -> human review -> analyze -> score -> prioritize -> inspect recommendation -> export/report.

## Success hypothesis
The product is successful when it reduces the time required for a first-pass automation assessment while improving consistency, traceability, and comparability—without pretending uncertain information is known.

## Deliberate non-goals for MVP
- Build or deploy the actual automation.
- Replace process owners or solution architects.
- Guarantee ROI.
- Ingest every enterprise file type.
- Be a complete BPMN modeling suite.
